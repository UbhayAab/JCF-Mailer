How it installs

  1. Tap Install On Android, Chrome and Edge the browser's own install prompt opens and does the rest.
  2. On an iPhone, tap Share instead Safari has no install button. Open the Share sheet, scroll down, choose Add to Home Screen.
  3. Open it from the home screen Full screen, no browser bar, sitting with your other apps.
